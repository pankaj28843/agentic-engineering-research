# Asset Notes

The research packet currently relies on text, tables, equations, and
publication-generated diagrams rather than copied web imagery. This keeps
provenance clear and allows the same source Markdown to flow into web, ebook,
and print layouts.

Any later image added here must record its source, license or generation
provenance, alt text, and the chapter that uses it. Bulky browser screenshots
and rendered-page captures belong in the gitignored `tmp/` tree, not here.
